# Beyond Clicks website (prototype)

A fast, static, mobile-first website for Beyond Clicks: Marketing, Staffing and Tools. Plain HTML, CSS and JavaScript with a tiny Node build script. No framework and no dependencies.

## Run it locally

```bash
node build.mjs                 # builds dist/ (folder-style links, for hosting)
npx serve dist                 # or: python3 -m http.server --directory dist
```

`node build.mjs --target=preview` builds `preview/` with explicit `index.html` links, which is the version used for the claude.ai preview link.

## Put it live on GitHub Pages

1. Create an empty GitHub repository, for example `beyond-clicks`.
2. Push this folder to its `main` branch.
3. In the repository, go to Settings, then Pages, and set Source to **GitHub Actions**.
4. Every push to `main` now builds and deploys the site automatically (`.github/workflows/pages.yml`).

The site uses relative links, so it works at `username.github.io/beyond-clicks/` and on a custom domain.

## Where things live

| What | Where |
| --- | --- |
| Domain, name, navigation, header buttons | `src/site.mjs` |
| Page content | `src/pages/*.mjs` |
| Design system (colors, type, buttons, glass hover) | `src/assets/css/style.css` |
| Tool layouts | `src/assets/css/tools.css` |
| CV Screener logic (runs in the browser) | `src/assets/js/cv-screener.js` |
| UTM Builder logic | `src/assets/js/utm-builder.js` |
| Sitemap, robots.txt, structured data | Generated by `build.mjs` |

To rename the tools section (for example `/tools` to `/labs`), change the paths in `src/site.mjs` and `src/pages/tools.mjs`.

## Before launch

- Set `SITE.url` and `SITE.email` in `src/site.mjs`.
- Replace everything marked **Placeholder** or **Draft** (case studies, team, legal pages).
- Connect the forms to a form service or email handler.
- Connect checkout for Screener Pro.
